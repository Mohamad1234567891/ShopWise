## 1. Sentiment Analysis Implementation

I contributed to the project's sentiment-analysis functionality in `SentimentAnalysis.py`, using Python and the Natural Language Toolkit (NLTK).

My work included:

- **Text tokenization:** Used NLTK's `word_tokenize` to split input text into tokens.
- **Text normalization and cleaning:** Worked on the `process_text` function to convert text to lowercase, tokenize it, and retain alphabetic tokens while filtering out English stopwords.
- **Sentiment scoring:** Used NLTK's `SentimentIntensityAnalyzer` with VADER to calculate sentiment scores for text.
- **Sentiment classification:** Worked on the `analyze_sentiment` function to use VADER's compound-score thresholds to classify text as **positive**, **negative**, or **neutral**.

This contribution provides a way for the project to process text and determine its overall sentiment, which can support sentiment-related analysis in ShopWise.
